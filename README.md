# Разработка удобного веб-приложения для «My School Learning Centre»: повышение прозрачности, коммуникации и планирования в обучении английскому языку

## 📌 Общий объектив проекта

Разработать и внедрить удобное веб-приложение для «My School Learning Centre», которое повысит прозрачность процессов, улучшит коммуникацию между участниками образовательного процесса и оптимизирует планирование занятий по английскому языку, тем самым улучшив качество обучения для студентов, родителей и преподавателей.

## 🎯 Специфические цели

- **Анализ влияния профилей преподавателей** на выбор студентов при записи в языковые центры. Выявление ключевых характеристик преподавателей, влияющих на решение учащихся.
- **Оптимизация процессов планирования** занятий через внедрение функций для минимизации конфликтов в расписании и повышения эффективности работы центра.
- **Оценка улучшенных каналов коммуникации** между студентами и преподавателями и их влияние на вовлеченность и качество обучения.
- **Исследование роли прозрачности** в операционных процессах приложения для укрепления доверия и удовлетворенности студентов.
- **Оценка дизайна и удобства приложения** на уровень вовлеченности пользователей, а также выявление лучших практик для образовательных платформ.

## 🚀 Запуск проекта | How to Run the Project

### 🖥 Backend

1. Перейдите в папку `api`:
   ```sh
   cd api
   ```
2. Запустите сервер:
   ```sh
   node index.js
   ```
3. Сервер будет запущен по адресу: [`http://localhost:4000`](http://localhost:4000)

### 🎨 Frontend

1. Перейдите в папку `client`:
   ```sh
   cd client
   ```
2. Запустите клиентскую часть:
   ```sh
   npm run dev
   ```
3. Откройте браузер и перейдите по адресу: [`http://localhost:5173`](http://localhost:5173)

## 📌 Технологии | Technologies Used

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB, AWS S3 storage
